## Where the investigation stands

The open question is why takers fail to fill against a book that is liquid on average.
It is NOT resolved. My last message overclaimed; the calibrated position is below.

### Measured (12h, seed 91, central venue ABC/USD, this scheduler and config)

- 41,751 steps. 99.5% contain an instant where the reconstructed book has no asks,
  99.5% no bids, 99.5% both sides empty at once.
- Dated carry desk: 572 spot orders accepted, 64 filled (11.2%). Futures legs fill reliably.
- One inspected IOC buy at 50.194 sat above the reconstructed best ask 50.118 at the
  same nanosecond and did not fill.
- Market -> tick-aligned IOC limit changed the order type and left the fill rate at 11.2%.
- Carry edge sweep 10/30/60/120 bps: -4,723 / -5,658 / -6,202 / -5,086 USD per member.
  No monotone trend.
- The same 99.5% figure appears independently as the two spot makers' share of traded volume.

### Evidence tiers

- **Demonstrated**: the book passes through an empty state within nearly every step;
  the carry desk's fill rate is far below what its prices imply.
- **Suggested, not proven**: that the desk's orders land in that empty instant. The link
  is a correlation plus one inspected order, not a per-order trace of match-time book state.
- **Falsified under this configuration only**: threshold calibration and order type as
  explanations for the carry desk's losses; stale pricing for the one order inspected.
- **Engineering judgment, not a result**: that the fix belongs in the maker.
- **Not ruled out**: that the intra-phase empty state is a reconstruction artifact of the
  delta stream, exposing states no actor ever matches against.

### Live alternatives, not mutually exclusive

1. Atomic quote replacement (submit before cancel) — code written, never run.
2. Bootstrap liquidity actors — permanently resting depth that never cancels. Previously
   dismissed on the grounds the book is not cold; that only rules out the cold-start reading.
   Strongest single discriminator: separates "is there depth" from "is there depth at my phase".
3. Realistic cancel/new latency — cancel and submit currently land in the same phase.
   Asymmetric latency could smear replacement across phases without touching quoting logic.
4. Randomized tick phase for takers — if the hole is phase-deterministic, jitter should move
   the fill rate toward the duty-cycle fraction while leaving the empty-step fraction alone.
5. Actor-level defensive behavior — contaminating only if the emptiness is an artifact,
   which is the thing under test rather than a premise.

## Pre-registered experiment design (nothing run yet)

12h, seed 91, otherwise the base config. Measure in every arm: empty-step fraction,
maker-vs-maker volume share, carry desk spot fill rate, population payoff table.

| arm | if "deterministic phase capture" holds | if it does not |
|---|---|---|
| submit-before-cancel | empty-step fraction to ~0; carry fill rate up; maker share down, **together** | one moves alone, or neither |
| randomized taker tick phase | fill rate up toward duty-cycle fraction; empty-step fraction unchanged | fill rate flat |
| cancel/new latency asymmetry | empty-step fraction down without changing quoting | no effect |
| bootstrap resting depth | fill rate up sharply while empty-step fraction stays high | fill rate flat, so emptiness is not what blocks fills |

Suggested order: bootstrap depth and submit-before-cancel first — together they
discriminate between the explanations rather than only fixing one.

After any fix lands, re-test the ideas rejected before it: removing one artifact can make
a previously useless mechanism (bootstrap actors especially) start to matter.
